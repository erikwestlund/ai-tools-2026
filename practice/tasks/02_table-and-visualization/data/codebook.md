# Community Clinic Visits Codebook

File: `data/community_clinic_visits.csv`

This is a small clean synthetic dataset for practicing a basic table and visualization workflow.

## Unit Of Observation

Each row is one synthetic clinic-month summary.

## Variables

- `clinic_id`: synthetic clinic identifier.
- `region`: broad geographic region.
- `clinic_type`: clinic category.
- `month`: reporting month.
- `visits`: number of recorded visits during the clinic-month.
- `followup_rate`: proportion of visits with documented follow-up.
